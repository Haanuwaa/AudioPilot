PowerShell
From the AudioPilot folder 
# Inspect AudioPilot status, device counts, and tuning as JSON
.\AudioPilot.Cli.exe status --json

# Lower a running app's volume by 5%
.\AudioPilot.Cli.exe app volume adjust -5 --process game

# Switch directly to a named playback device
.\AudioPilot.Cli.exe switch output --device "Headset"

FAQ

Common questions

Quick answers on system requirements, Windows SmartScreen warnings, updates, and troubleshooting.

Open the full user guide
Which Windows versions are supported?

AudioPilot requires Windows 10 version 2004 (build 19041) or later. Official support covers Windows 11 and supported Windows 10 Enterprise/LTSC editions that meet that minimum, subject to the Microsoft and .NET 11 support lifecycles. A CPU supported by .NET 11 is required; older x86/x64 CPUs such as Intel Core 2 are not supported.

Why does Windows show a download warning?

AudioPilot does not yet have a publicly trusted code-signing certificate. Windows may show an unknown-publisher or SmartScreen warning. Read the download guidance before opening it. Work-managed PCs may also apply their own software policies.

Do I need to configure everything upfront?

No. Start with just the controls you want. You can use the volume mixer, media controls, and microphone shortcuts without setting up a device switch order or routines. The setup guide walks through the first steps.

Does AudioPilot update itself automatically?

Only with your approval. Optional checks notify you when a newer release is available without downloading packages in the background. Official stable packages offer Update and restart, which downloads, verifies, and installs after you approve while keeping AudioPilot running until replacement is ready.

Which languages are supported?

English and Spanish. Change Language in Settings to switch the interface immediately without losing unsaved edits or interrupting active operations. CLI commands and output stay in English for predictable scripts.

Where can I report a bug or suggest a feature?

Use GitHub Discussions for questions and ideas, or open an issue on GitHub. For troubleshooting, the app can save a redacted support bundle on demand — review it before sharing.
