Same controls.

Use the GUI for everyday adjustments, or the CLI for scripts and automation. On-demand diagnostics and redacted support bundles help when something needs a closer look.

Read the CLI reference ↗
PowerShell Example commands
# See the current audio state
AudioPilot.Cli.exe status --json

# Lower an app's volume
AudioPilot.Cli.exe app volume adjust -5 --process game

# Switch to a named output
AudioPilot.Cli.exe switch output --device "Headset"

05 Notes from the manual

Before you
plug in.

Open the full user guide ↗
Which Windows versions can I use?

AudioPilot requires Windows 10 version 2004 (build 19041) or later. Official support covers Windows 11 and supported Windows 10 Enterprise/LTSC editions that meet that minimum, subject to the Microsoft and .NET 10 support lifecycles.

Why does Windows show a download warning?

AudioPilot does not yet have a publicly trusted signing identity. Windows may show an unknown-publisher or SmartScreen warning. Read the download guidance before opening it. Work-managed PCs may also apply their own software policies.

Do I need to set up everything?

No. Start with the controls you need. You can use volume and microphone shortcuts without configuring a device-switch list. The setup guide walks through the first steps.

Does AudioPilot update itself?

No. Optional update checks show a release link when a newer version is available. Downloading and installing an update stays in your hands.

Where can I report a problem or suggest an idea?

Open an issue on GitHub. For troubleshooting, the app can save a redacted support bundle on demand. Review it before sharing.
